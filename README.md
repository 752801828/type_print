# 飞页 · 飞书排版打印

独立于“印序”的个人飞书侧边插件 MVP。它只在浏览器侧读取当前多维表的选中记录，把字段值提交给本服务，按绑定模板生成文件；不复用旧项目的账号、数据文件、端口或密钥。

## 已实现

- `/feishu` 侧边插件入口和独立的版式工作台界面。
- 使用官方 `@lark-base-open/js-sdk@0.3.8` 读取当前 Base、数据表、视图、字段和选中记录；通过 `field.getCellString(recordId)` 兼容飞书返回的记录代理对象。
- 上传、列出和删除 DOCX/XLSX/XLS/PDF 及飞书在线布局导出（TXT/LAYOUT/JSON）模板；模板绑定当前 Base/数据表，只在同一数据表下显示。
- 模板列表提供“预览”：PDF 直接内嵌查看，DOCX/XLSX 显示内容和变量，飞书在线布局按页面、表格、合并单元格和变量渲染，XLS 提供原文件在线打开/下载。
- 左侧模板库默认收起，点击“菜单”展开；只显示当前项目实际上传的模板，不显示示例模板、登录用户或团队信息。
- “字段匹配诊断”可展开当前模板变量、匹配字段和字段 ID。
- 飞书表格行首复选框优先于活动单元格；勾选一行或多行后自动读取，未勾选时读取当前活动行。关联字段会填充 `{#循环名}…{/循环名}`。
- DOCX 使用 `docxtemplater` 保留原有字体、表格和分页，支持 `{字段}` 及 `{#items}…{/items}` 语法；XLSX 做基础占位符替换；在线布局单条记录输出带页面和表格样式的 HTML；XLS/PDF 可原格式导入和导出（首版不改写二进制内容）。
- 批量生成直接使用飞书原生勾选行，不再加载整张视图或维护插件内第二套复选框。
- 只读取当前模板需要的主表与关联表字段，避免扫描无关字段和关联字段依赖。
- 生成文件存放在独立 `data/outputs`，通过带随机 ID 的下载接口返回。
- 显式静态目录白名单；`data/` 不可通过静态 URL 访问。

## 启动

要求 Node.js 20+。

```powershell
cd "C:\Users\WY001\Documents\New project 6\feishu-layout-print-plugin"
$env:PORT="4318"
npm install
npm start
```

打开 <http://localhost:4318/>；飞书自定义插件运行地址填写 `http://106.15.63.180:4318/feishu`。4318 是本项目端口，不使用 4177，也不会停止其他项目。

端口确认：`4177` 返回的是另一个项目“印序”，不要把它配置到本插件。新项目必须使用 `4318`，入口为 <http://106.15.63.180:4318/feishu>，健康检查会返回 `build: feiye-independent`。

发布前检查：服务器必须使用公网 HTTPS；扩展脚本 URL 直接填写 `/feishu`，不要填写 `/api` 或需要登录跳转的地址。开发环境可用飞书支持的本地调试/HTTPS 隧道；脱离飞书打开时显示“宿主不可用”是预期降级状态。

### 飞书报错排查

- `Failed to read the 'headers' property from 'RequestInit'`：模板中文文件名不能直接放入请求头；当前版本会先用 `encodeURIComponent` 编码，服务端再还原文件名。
- `Cannot read properties of undefined (reading 'fidybdWjSn')`：这是旧代码把 Base SDK 的记录代理当成 `{ fields }` 普通对象读取；当前版本已改用 `field.getCellString(recordId)`，重载插件后即可。
- `not registered`：表示飞书宿主没有注册当前扩展事件或页面不是从多维表“扩展脚本”打开；当前版本会捕获该异常并启用 700ms 自动选区轮询，仍应把运行地址配置为 `http://106.15.63.180:4318/feishu`。
- 页面能打开但显示“宿主不可用”：说明页面不在飞书多维表扩展脚本宿主中；请在多维表“扩展脚本”中直接配置 `http://106.15.63.180:4318/feishu`。正式部署建议再换成 HTTPS 域名。
- 修改前端后仍显示旧页面：删除并重新添加扩展脚本，使用固定入口 `http://106.15.63.180:4318/feishu`；服务端使用 `no-store`，页面资源不使用版本后缀。

## 审核提交包

在本项目根目录运行 `npm run build`，再运行 `npm test`。提交内容必须包含同一级的 `package.json`、`build.mjs` 和 `dist/index.html`；输出目录为 `dist`。不要只提交 `public` 或把整个项目多套一层文件夹。

`dist` 已纳入 Git 跟踪。通过仓库提交审核时，请确认审核选中的分支/提交包含最新构建产物；本地构建成功不代表审核端已更新。静态发布版仍依赖 `https://gzwy.online/feishu` 的后端 API，修改 `lib` 后须单独更新后端。

旧版占位符按 UTF-16 字符单元把空格、标点、图标转为下划线，例如 `单价(含税)💻 → 单价_含税___`，优先精确匹配，再兼容旧别名。单价只读取字段值，缺失时保持为空，不从总价和数量推算。

## 模板示例

在 Word 中输入：

```text
客户：{客户名称}
订单号：{订单号}
明细：
{#items}{品名} / {数量}{/items}
```

“读取记录”直接使用飞书行首复选框勾选的记录；未勾选时使用当前活动行。单条记录下载 DOCX，多条记录自动生成 ZIP。

## 独立数据边界

| 目录/端口 | 用途 |
| --- | --- |
| `public/` | 插件前端 |
| `lib/` | 模板保存与 DOCX 渲染 |
| `data/templates/` | 上传模板二进制 |
| `data/outputs/` | 生成文件 |
| `data/templates.json` | 模板元数据 |
| `4318` | HTTP 服务端口 |

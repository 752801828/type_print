# 飞页 · 飞书排版打印

## 已实现

- `/feishu` 侧边插件入口和独立的版式工作台界面。
- 使用官方 `@lark-base-open/js-sdk@0.3.8` 读取当前 Base、数据表、视图、字段和选中记录；通过 `field.getCellString(recordId)` 兼容飞书返回的记录代理对象。
- 上传、列出和删除 DOCX/XLSX/XLS/PDF 及飞书在线布局导出（TXT/LAYOUT/JSON）模板；模板绑定当前 Base/数据表，只在同一数据表下显示。
- 模板列表提供“预览”：DOCX 由浏览器按 OOXML 页面布局渲染，保留页面尺寸、字体、表格、图片、页眉页脚和分页；PDF 直接内嵌查看，XLSX 显示工作表布局，飞书在线布局按页面、表格、合并单元格和变量渲染。
- 左侧模板库默认收起，点击“菜单”展开；只显示当前项目实际上传的模板，不显示示例模板、登录用户或团队信息。
- “字段匹配诊断”可展开当前模板变量、匹配字段和字段 ID。
- 飞书表格行首复选框优先于活动单元格；勾选一行或多行后自动读取，未勾选时读取当前活动行。关联字段会填充 `{#循环名}…{/循环名}`。
- DOCX 使用 `docxtemplater` 保留原有字体、表格和分页，支持 `{字段}` 及 `{#items}…{/items}` 语法；XLSX 做基础占位符替换；在线布局单条记录输出带页面和表格样式的 HTML；XLS/PDF 可原格式导入和导出。
- 批量生成直接使用飞书原生勾选行，不再加载整张视图或维护插件内第二套复选框。
- 只读取当前模板需要的主表与关联表字段，避免扫描无关字段和关联字段依赖。
- 生成文件存放在独立 `data/outputs`，通过带随机 ID 的下载接口返回。
- 显式静态目录白名单；`data/` 不可通过静态 URL 访问。

## 独立数据边界

| 目录/端口 | 用途 |
| --- | --- |
| `public/` | 插件前端 |
| `lib/` | 模板保存与文档渲染 |
| `data/templates/` | 上传模板二进制 |
| `data/outputs/` | 生成文件 |
| `data/templates.json` | 模板元数据 |
| `4318` | HTTP 服务端口 |
